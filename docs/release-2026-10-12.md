# lookover 组合发行 · 2026-10-12

本轮将气泡、页面上下文和经验记忆统一为“在当前页面提问，把解决经验留给下次”。三者仍可独立安装；先体验气泡＋Look，再按需加入经验记忆。

## 发布内容

- `dsh-bubble@0.3.4`：将已验证的 companion 0.3.3 以正式名称打包，保留原生应用标识以兼容过滤与外观偏好。加入用户使用说明、主题截图和明确宿主声明。
- `dsh-look@0.1.1`：采用本机已验证的官方只读适配，排除官方主窗口和原生气泡。发行入口不启动旧壳全局键盘监听器，不包含未提交的 operate 操作草稿；此次预编译包为 arm64。
- `dsh-expmem@0.1.1`：修复官方工具输出格式校验。原来把所有输出声明为空对象且禁止额外字段，保存结果被拒；列表实际返回数组，也与对象声明不符。现在对象输出允许真实记录字段，列表声明为对象数组。
- 四份 README 先展示用户收益、组合流程、安装和边界；包描述互相指向另外两个插件。移除跟踪的 Demo 运行数据，发行包只含 Demo 脚本。

## 气泡 Markdown 修复（0.3.5，同日后续）

用户发现回复的双星号和三反引号直接显示。根因是原 MessageCard 把模型返回的 Markdown 字符串以纯文本放入 NSTextView，没有解析与样式转换。0.3.5 用 Foundation 的完整 Markdown 解析，再显式恢复段落、列表和换行并映射 AppKit 字体；不删除原始会话里的标记，不对全文做星号／反引号替换。

支持粗体、斜体、标题、列表、引用、删除线、行内代码、围栏代码块及 http／https 网页链接。代码块内的颜文字、星号、空格、缩进与换行按原文本保留。用户消息保留原文；逐字符流式前缀通过解析与布局回归，未闭合代码围栏也可显示。表格保留源码，避免合并单元格改变语义；图片不自动加载，HTML 不执行。稳定历史消息的排版缓存跨流式帧复用，换肤时清空；缓存仅保留当前显示消息。

12 项回归通过，包含新增的原生 Markdown 检查及既有输入／皮肤／窗口／会话桥接检查。默认与小光主题的截图使用独立模拟验收内容。日用本地 companion 使用同一显示修复，保留原包名，版本 0.3.4；公开 dsh-bubble 为 0.3.5。其他插件版本不变。此修复不等于完整 Markdown 富媒体、表格或工具审批往返已实现。
